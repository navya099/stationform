# StationForm

노선 기획과 개념설계 단계에서 철도역사의 부지와 배치 대안을 검토하는 오프라인 데스크톱 도구다.

대상은 토공구간 선상·선하역사와 고가구간 고가역사다. LandXML 선형과 DEM 또는 LandXML 지표면을 기준으로 역사 본체, 승강장, 광장, 진입로와 연결시설을 계획한다. 최종 산출물은 LOD 100~200 IFC 모델, DXF 배치도·평면도·입면도·단면도, CSV 집계표와 건축설계설명서다.

StationForm의 프로젝트 모델은 선로·측점·계획고, 패밀리 유형과 배치 객체, 설계 대안별 수정값을 관리한다. 도면과 집계는 같은 대안 버전에서 생성한다. 범용 계산과 파일 처리에는 CivilCraft와 BIMCraft 모듈을 우선 검토한다.

## 부지 검토 개발 도구

미터 단위 LandXML 한 파일에서 선형, 계획 종단과 현황 TIN을 선택한다. 지정 측점의 레일면과 승강장 연단 위치·높이, 현황 및 대안별 계획 횡단면, 개략 절·성토량을 JSON으로 출력한다. 광장 계획고를 바꿔도 대안마다 같은 현황 TIN을 기준으로 계산한다.

Node.js 24와 아래 CivilCraft 리비전의 체크아웃이 필요하다. 첫 데스크톱 실행에서는 Electron 실행 파일을 내려받을 수 있으며, 개발 환경을 준비한 뒤에는 로컬에서 실행된다.

```sh
git clone https://github.com/getcadcraft/civilcraft.git ../civilcraft
git -C ../civilcraft checkout a83c0c1011ef1c0d4bb9f2e9c39bc18a4cf016f7
npm ci
npm test
npm run desktop -- ../civilcraft
npm run --silent study:civil -- ../civilcraft fixtures/concept-station.xml fixtures/concept-study.json
npm run verify:civil -- ../civilcraft
```

[샘플 설계 조건](fixtures/concept-study.json)에서 선형·종단·지표면 인덱스는 0부터 시작한다. 오프셋은 측점 증가 방향을 기준으로 우측이 양수이며, 절·성토 사면은 수평 거리와 높이의 비율(H:V)로 입력한다. 토공량은 대안별 사면 접합 경계 안에서 격자로 근사한다.

데스크톱 개발판은 샘플을 열어 배치 평면, 횡단면, 대안별 토공량 비교표를 표시한다. 기준 측점이나 선택 대안의 광장 계획고를 바꾼 뒤 **계산 적용**을 누르면 결과가 갱신된다. 자체 파일은 **LandXML 열기**와 **설계 조건 열기**에서 각각 선택한다.

**프로젝트 저장**은 LandXML 원본, 편집한 설계 조건과 표시 대안을 하나의 `.stationform` 파일로 저장한다. 처음 저장할 때 경로를 고르고, 이후 저장은 그 파일에 반영한다. **프로젝트 열기**는 저장한 조건을 복원하고 부지 검토 결과를 다시 계산한다. 현재 파일 형식은 버전이 지정된 JSON이다.

**DXF 저장**은 선택한 대안의 배치 평면과 횡단면을 각각 CivilCraft R12 DXF로 내보낸다. 배치 평면은 입력 평면 좌표를 유지하고, 횡단면은 횡단 오프셋과 표고를 X·Y로 사용한다. 도면 공간에서 한 단위는 1m다. **CSV 저장**은 모든 대안의 토공량과 격자 크기, 계산 면적을 UTF-8로 내보낸다. 각 산출물에 같은 계산 ID가 기록된다. 측점이나 광장 계획고를 편집하면 계산을 다시 적용한 뒤 내보낼 수 있다.

**PDF 저장**은 현재 부지 검토 범위의 건축설계설명서를 A4로 생성한다. 선로·측점·승강장 개요, 모든 대안의 토공량 비교, 선택 대안의 배치 평면과 횡단면을 담는다. **설계 설명 작성**에서 작성한 설계 의도와 대안 채택 사유는 PDF에 반영되고 프로젝트에도 저장된다. PDF의 계산 ID는 같은 계산에서 내보낸 DXF와 CSV의 ID와 일치한다.

**역사 매스**를 켜고 형식을 선택하면 기준 측점의 선로 중심과 접선 방향에 직육면체 본체를 배치한다. 모든 형식에서 길이·폭·높이를 편집할 수 있다. 매스는 광장 계획고 대안들이 공유하며, 배치·횡단 DXF와 PDF에 표시된다.

| 역사 형식 | 본체 표고 기준 |
| --- | --- |
| 선상역사 | 기준 레일면에 바닥 높이를 더한다. |
| 선하역사 | 기준 레일면에서 지정 깊이를 빼 지붕을 놓고, 본체 높이만큼 아래에 바닥을 놓는다. |
| 고가역사 하부 | 기준 측점의 현황 지표면에 바닥 높이를 더한다. 지붕이 기준 레일면보다 높은 조건에서는 배치할 수 없다. |

기존 형식 없는 매스는 선상역사로 연다. 고가역사 하부에는 본체 높이를 수용할 수 있는 선로와 지표면의 표고 차가 필요하다. 이 단계의 표고 조건은 기준 측점에서 계산하며, 고가 측면 배치, 지지 구조, 선하부 굴착 및 건축한계 검토는 이후 범위다.

**IFC 저장**은 선택 대안을 IFC 4.3 개념 모델로 생성한다. 역사 본체 매스, 종단 표고를 따르는 승강장 표면, 광장과 사면을 포함한 계획 지표면을 담는다. 프로젝트 속성에 계산 ID, 대안, 측점, 표고와 토공량을 기록한다. 좌표와 표고는 프로젝트의 미터 좌표로 유지하고, LandXML의 좌표계 정보가 있으면 출처 속성에 기록한다. 좌표 변환과 승강장 구조 두께는 적용하지 않는다.

검증에는 가상 좌표의 직선 선로와 평탄한 지형을 사용한다. 지형과 선형은 공통 좌표·수직 기준으로 준비해야 한다. 승강장은 개념 배치이며 캔트 보정, 실제 곡선 노선 검증, 건축 층별 평면·입면, 건축 규모·접근 계획 등 설명서의 추가 항목과 독립 설치 패키징은 이후 구현 범위다.
